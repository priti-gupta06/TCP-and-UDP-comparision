# TCP-and-UDP-comparision
compare TCP and UDP communication ad identify appropriate use cases .



Overview :

This project focuses on understanding and comparing TCP and UDP, two transport-layer protocols used for data communication over networks.
It explains how they work and how their features affect network communication.

Aim :

To analyze TCP and UDP based on reliability, connection establishment, data transmission, and protocol overhead.

Methodology :

1. Study the basic concepts of TCP and UDP.
2. Compare their connection behavior and reliability.
3. Identify their advantages and limitations.
4. Explore common applications of both protocols.
5. Document the findings and comparison.

TCP vs UDP :

- TCP: Establishes a connection and supports reliable, ordered data delivery through acknowledgments and retransmissions.
- UDP: Sends datagrams without establishing a connection and offers lower protocol overhead without built-in delivery guarantees.

Applications :

TCP _
- Web browsing using HTTPS
- Email communication
- File transfers
- Secure remote access using SSH

UDP _
- Real-time voice and video communication
- Online gaming
- DNS queries
- Latency-sensitive applications

Learning Outcomes _

- Understood the role of transport-layer protocols.
- Learned the difference between connection-oriented and connectionless communication.
- Identified suitable use cases for TCP and UDP.
- Improved understanding of network reliability and communication overhead.

Conclusion _

TCP and UDP are essential protocols for network communication. TCP is suitable for applications requiring reliable and ordered delivery, while UDP is often useful for applications that prioritize low latency and reduced overhead.
